# Исламские Reels на Remotion — от и до

Скилл собран из реальной работы над серией исламских роликов (авторская страница и заказы для школ Корана).
Здесь — процесс, правила и готовые инструменты. Подробности — в `references/ru/`, код — в `assets/remotion-kit/`
и `scripts/`. Читай справочник, когда доходишь до соответствующего шага.

Общайся с пользователем на его языке (правила и примеры здесь — на русском, но работают для любого языка
озвучки: Whisper и шрифты поддерживают и русский, и английский, и арабский).

## Главное (почему правила такие)

1. **Сначала показать — потом рендерить.** Скриншоты ключевых кадров (и короткое превью в половинном
   разрешении, если важно движение) → правки → только после «рендер» финальный MP4. Исключение — если
   пользователь сам сказал «рендери сразу». Рендер долгий, а правки после него дорогие.
2. **Моушн-дизайн, а не «текст на картинках».** Слайд-шоу из картинок подряд выглядит дёшево и смотрится хуже.
   Каждая сцена — фон + движение (камера, свет, частицы, дым) + графика (инфографика, рамки, линии,
   переходы); между фото — графические экраны на анимированном фоне. → `references/ru/visual-style.md`
3. **Строгие эстетичные титры капсом**, слово в слово по озвучке, ровные строки, всё внутри безопасной
   зоны Reels. → `references/ru/captions-and-safe-zone.md`
4. **Шариатская аккуратность.** Не изображать Пророка ﷺ, сподвижников, ангелов; люди — без лиц, женщины —
   в полном джильбабе; арабский текст аятов/хадисов — только набором в коде, никогда из ИИ-картинки;
   каждый аят и хадис проверен по источнику. → `references/ru/religious-content.md`
5. **Звук:** голос чистый и разборчивый; фон — только нашид без инструментов или тихий эмбиент без
   музыки; эффекты почти неслышные. → `references/ru/audio.md`
6. **Люди и сложные объекты — картинками из ИИ** (пользователь генерирует по твоим промтам), абстракция,
   инфографика, растения, свет, орнамент — кодом. Персонажей в коде не рисовать: выходит грубо и «мультяшно».
   → `references/ru/image-prompts.md`

## Процесс

### 0. Приём материалов
- Озвучка (часто ElevenLabs mp3 с метками `[calm]`, `[whispers]`; или голосовое клиента ogg) и текст.
- Для клиента — логотип, фирменные цвета, название организации.
- Узнай и зафиксируй (настройки ролика):
  - **водяной знак** — ник автора (`WATERMARK.text` в ui.tsx) или без знака (заказ клиента);
  - **палитра** — по умолчанию «тёмный космос + золото» или фирменные цвета (`C` в ui.tsx);
  - **фон** — нашид без инструментов (пришлют) или тихий эмбиент;
  - **ускорение голоса** — обычно +2…4 %;
  - **«Подписывайся» в конце** — оставить или обрезать.
- Сценарий ещё не написан? Если доступен скилл `islamic-reel-script` — сценарий пишет он.

### 1. Проверка содержания (до любых картинок)
Проверь каждый аят (сура:аят, арабский текст) и хадис (сборник и номер, точная формулировка), цифры и
научные утверждения. Найдёшь расхождение — скажи прямо и предложи правку (например, «в хадисе аль-Бара —
„О благая душа“, а „спокойная душа“ — слова аята 89:27; перегенерируйте эту фразу»). → `references/ru/religious-content.md`

### 2. План, стиль и список картинок
- По тексту/озвучке разбей ролик на сцены (по смыслу, 3–10 с), для каждой: фон (картинка или графика),
  движение/эффект, инфографика, переход. Хук — первые 2 секунды.
- Предложи 2–3 стиля (можно стайлборды-стиллы кодом) или следуй стилю страницы/бренда.
- Дай пользователю **полный список картинок с готовыми промтами** (копировать целиком). → `references/ru/image-prompts.md`
- Для клиента — сценарий по таймкодам «время · текст · визуал».

### 3. Проект
```bash
bash <skill>/scripts/new_project.sh <repo> rolikN     # каркас из assets/remotion-kit + шрифты (get_fonts.py)
```
Структура и правила репозитория → `references/ru/project-and-delivery.md`. Компоненты → `references/ru/remotion-kit.md`.

### 4. Звук и тайминги
```bash
python3 scripts/prep_voice.py audio_src/voice.mp3 rolikN/public/audio/voice.wav --tempo 1.02 [--denoise] [--keep 30.6:0.6]
python3 scripts/transcribe.py rolikN/public/audio/voice.wav /tmp/w.json          # слова с таймингами
python3 scripts/align.py /tmp/w.json rolikN/script.txt rolikN/src/words.json     # текст → тайминги
python3 scripts/gen_sfx.py rolikN/public/sfx [--ambient rolikN/public/audio/amb_wind.mp3 --duration 155]
python3 scripts/mix_bed.py nasheed.mp3 rolikN/public/audio/voice.wav rolikN/public/audio/bed.mp3 --duration 122
```
`script.txt` — текст **как он произнесён** (если голос сказал «тем», а в тексте «всем» — титр по голосу,
и сообщи пользователю). Один абзац = одна строка → номер для `W(абзац, "слово")`.

### 5. Картинки
```bash
python3 scripts/prep_art.py bg src.png rolikN/public/art/name.jpg        # фон 9:16 с апскейлом
python3 scripts/prep_art.py defringe src.png rolikN/public/art/cut.png   # вырезка без каймы
python3 scripts/prep_art.py fromblack logo.jpg rolikN/public/art/logo.png
```
Найди координаты важных точек на картинках (солнце, лица фигур, горизонт) — по сетке-превью или
по яркости (numpy) — для подписей, бликов, прицелов.

### 6. Сборка сцен
`src/Scenes.tsx`: `T` (границы сцен через `W()`/`WE()`), `shots` (фон + камера + переход),
`Overlays` (титры, цитаты, инфографика). Примеры целиком: `assets/examples/rolik4-Scenes.tsx` (космос +
инфографика), `rolik5-Scenes.tsx` (сад-метафора, бренд клиента).

### 7. Проверка
```bash
node scripts/stills.mjs rolikN /tmp/st 30 200 450 ...      # ключевые кадры
python3 scripts/contact_sheet.py /tmp/st sheet.jpg [--safe] # лист для показа
node scripts/probe.mjs rolikN /tmp/probe.txt 0 <frames> 8 && python3 scripts/check_safe.py /tmp/probe.txt
npx remotion render Reel /tmp/preview.mp4 --scale=0.5 --crf=26   # превью движения (не финал)
```
Сам посмотри листы перед отправкой: вылеты текста, огласовки в арабском, «пустые» кадры, повторы.
Отправь пользователю листы (и превью), коротко перечисли, что где происходит.

### 8. Финал
```bash
cd rolikN && npx remotion render Reel out/rolikN.mp4 --crf=20 --audio-bitrate=192k
```
Проверь: длительность, ≤ 90 МБ, громкость (≈ −14…−16 LUFS, пик ≤ −1 dB), кадры из готового MP4.
Закоммить MP4 и исходники, запушь, дай ссылку на GitHub. Предложи описание для Instagram с источниками
хадисов и промт обложки. → `references/ru/project-and-delivery.md`, `references/ru/covers.md`

## Что нужно установить
Node.js 20+, ffmpeg (с фильтром rubberband), Python 3.10+ с `numpy pillow faster-whisper`, curl.
Браузер для рендера Remotion скачивает сам. Remotion распространяется по своей лицензии (remotion.dev/license).
