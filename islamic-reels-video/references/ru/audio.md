# Звук

## Голос (`scripts/prep_voice.py`)
- **Ускорение** обычно +2 % (ElevenLabs) … +4 % (живой голос клиента). Только rubberband
  (`formant=preserved`, `pitchq=quality`) и только в WAV — atempo и повторное сжатие дают «металл».
  Пользователь просит «без искажений» — дай послушать 15–20 с, если сомневаешься.
- **Паузы:** длиннее 0.6 с укорачиваются до ~0.45 с; смысловые переходы (смена сцены, после сильной цифры)
  оставляй длиннее через `--keep время:длина`. Склейки — по тишине с перекрёстным затуханием 12 мс.
- **Чистка:** `highpass 60 Гц`; `--denoise` (afftdn) для голосовых из мессенджеров.
- **Громкость:** голос ≈ −16 LUFS моно, лимитер −1.5 dBFS. В стерео-миксе Remotion моно звучит на ~3 дБ
  громче → итог ролика ≈ −13…−14 LUFS — это нормально для Instagram.
- **Тайминги** считаются по обработанному файлу (сначала prep_voice, потом transcribe/align).
- Ошибка в озвучке (не та формулировка хадиса, слово) — предложи перегенерировать одну фразу в ElevenLabs
  и вставить на место (ffmpeg concat с короткими кроссфейдами).

## Фон
- **Нашид без инструментов** (присылает пользователь): `scripts/mix_bed.py` — зацикливание с
  кроссфейдом 4 с, базовый уровень −13 дБ, приглушение под голос (sidechain, ~5–6 дБ), итог ≈ −31 LUFS
  (на ~15 дБ тише голоса), плавный вход и выход. Громкость нашида в пиках 2–3 с пауз не должна «выпрыгивать».
- **Эмбиент без музыки** (если нашида нет или клиент просит): ветер на весь ролик (`gen_sfx.py --ambient`,
  ≈ −34 LUFS), по сценам — дождь, птицы, далёкий огонь; громкость в Remotion 0.2–0.75, плавные фейды.
- Никакой инструментальной музыки, битов, песен; никакого постоянного шипения/шума.

## Эффекты (`scripts/gen_sfx.py`)
Все синтезированы из шума (без музыкальных тонов): whoosh (переходы), tick (цифры, фонари, подписи),
lock (прицел), boom (мягкий удар на ключевой цифре), roll (счётчик крутится), riser (разгон),
thud (падение), crack (трещина), leaf (шорох), sparkle/shimmer (каллиграфия, аят), birds, rain, fire.

Уровни в Remotion (`volume`): whoosh 0.03–0.04, tick 0.02–0.05, shimmer 0.03–0.04, lock 0.05–0.06,
thud/boom 0.1–0.12, дождь 0.2. Пользователь дважды говорил «эффекты слишком громкие» — лучше тише.
Эффект ставь на слово/событие, а не «везде»: 1 эффект на 2–4 секунды максимум.

## Проверка готового MP4
```bash
ffmpeg -i out.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -A20 Summary   # I ≈ −13…−16 LUFS, Peak ≤ −1 dB
ffmpeg -ss 40 -t 5 -i out.mp4 -af volumedetect -f null -                    # уровни в паузах/речи
```
