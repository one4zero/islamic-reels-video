# Титры, цитаты и безопасная зона Reels

## Титры повествования (`Cap` в type.tsx)
- **Шрифт:** Montserrat 600, капс, трекинг 0.045em, цвет кремовый (#f3efe7), тень для читаемости.
- **Акценты:** `*слово*` — золото (#e6c27a); для «огня» — `tone="ember"`. 1–2 акцента на фразу.
- **Появление:** слово проявляется ровно в момент, когда его произносят (подъём на 16 px + расфокус →
  резкость, 10 кадров). Без прыжков, вращений, «пружин» — строго.
- **Выход:** весь блок гаснет за ~9 кадров с лёгким подъёмом; следующий титр начинается, когда старый ушёл.
- **Строки:** вручную через ` | `, 2 строки (максимум 3), длины примерно равные («строка строка / строка»
  — плохо). Ширина блока 820 px. Ориентир: при size 54 — до ~19 знаков в строке, при 48 — до ~21,
  при 46 — до ~23. Длиннее — разбей или уменьши size (не ниже 44).
- **Фразы:** одна смысловая фраза озвучки = один титр (3–8 слов). Не держи на экране больше ~4 с без смены.
- **Цифры:** пиши цифрами («117 миллиардов», «7%», «3 700 лет»): выравнивание само сопоставит их со словами
  озвучки («ста семнадцати»).
- **Имя Пророка:** «Пророк ﷺ сказал:» — знак ﷺ берётся из шрифта Amiri автоматически.
- **Никакой отсебятины:** титр = то, что сказано голосом (не письменный вариант, если они расходятся).

## Цитаты аятов и хадисов (`Quote`)
- Стеклянная панель: тёмный полупрозрачный фон с размытием, золотая рамка прорисовывается по периметру,
  ромбы в углах.
- Сверху — источник капсом с трекингом: «СУРА МАРЬЯМ · 19:94», «АЛЬ-БУХАРИ 7512 · МУСЛИМ 1016».
- Арабский (Amiri, золото, блик) — **только набранный текст**, сверенный с мусхафом/сборником.
  Длинный аят — на 2 строки (`textWrap: balance`), ۝ между аятами допустим.
- Перевод — Lora italic 600, обычный регистр (не капс: длинный сакральный текст в капсе читается тяжело),
  «ёлочки», слова по озвучке; акценты золотом.
- Пометки уважения: «Аиша (رَضِيَ اللَّهُ عَنْهَا)» — малой строкой `arabicSub`; «Он ответил» — `arabicSub="ﷺ"`.

## Каллиграфия (`Calligraphy`)
Салям, «الْحَمْدُ لِلَّهِ», «قَالَ النَّبِيُّ ﷺ», «رَبِيعَ قُلُوبِنَا» — крупно, золото с бегущим бликом.
Огласовки (харакат) должны быть видны: у текста с `background-clip: text` нужен вертикальный padding
(в наборе уже стоит `padding: 0.45em`), иначе знаки над/под буквами обрезаются.

## Подписи, числа, плашки
- `Kicker` — маленькая подпись капсом (21–24 px, трекинг 0.3em) с золотыми линиями по бокам.
- Цифры — Montserrat 250, `tabular-nums`, золото со свечением; табло 117 000 000 000 — не больше 92 px.
- `NamePlate` — «МЕНЯ ЗОВУТ / Имя / 42 ГОДА» (имя — Lora с засечками, блик).
- `Statement` — крупная фраза с засечками для кульминации («У пути к Корану / нет возраста»).

## Безопасная зона Reels (1080×1920)
```
сверху   0–250    шапка Reels                 — текста нет
снизу    1480–1920 ник, подпись, аудио, кнопки — текста нет
справа   x > 950 при y 1000–1480 колонка кнопок — текста нет
слева    x < 100                               — текста нет
```
- Весь текст (титры, цитаты, подписи, водяной знак, цифры) — внутри x 100…950, y 250…1480.
- Графика и фон могут заходить в зоны интерфейса.
- Для обложки в сетке профиля кадр режется до 3:4 (y 240…1680) — см. covers.md.

## Проверка (обязательно перед показом)
1. Пометь текстовые блоки `data-safe="…"`, у титров/цитат — `data-lines` (в наборе уже есть).
2. `node scripts/probe.mjs <проект> log.txt 0 <кадров> 8` → `python3 scripts/check_safe.py log.txt`.
3. Исправь: вне зоны — сдвинь/уменьши; лишние переносы — разбей строки короче или уменьши size;
   наложения дольше 1 кадра — разведи по времени или по высоте.
4. Покажи пользователю лист кадров с нанесённой зоной: `contact_sheet.py --safe`.
