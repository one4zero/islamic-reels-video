# Проект, рендер, сдача

## Репозиторий
- Каждый ролик — своя папка в корне: `rolik1/`, `rolik2/`… (следующий свободный номер). Код и ассеты
  роликов не смешивать.
- Внутри: `src/`, `public/{audio,art,sfx,fx,fonts}`, `scripts/` (скрипты именно этого ролика), `audio_src/`
  (исходники клиента: ogg, логотип, картинки), `script.txt` (текст как произнесён), `out/rolikN.mp4`, README.
- `.gitignore`: node_modules, dist, build, .env. **`out/` не игнорировать** (финальный MP4 коммитится).
- Ключи и токены — только из переменных окружения, никогда в файлах.
- Корневой `CLAUDE.md` проекта — правила (папки, MP4 ≤ 90 МБ, ключи, звук без инструментов).

## Рендер
```bash
npx remotion render Reel out/rolikN.mp4 --crf=20 --audio-bitrate=192k --concurrency=4   # финал
npx remotion render Reel /tmp/preview.mp4 --scale=0.5 --crf=26                           # превью движения
npx remotion render Reel /tmp/part.mp4 --frames=0-359 --scale=0.5                        # кусок
```
- Финальный MP4 ≤ 90 МБ → коммит + push (GitHub предупредит о файлах > 50 МБ — это нормально).
  > 90 МБ — повысить CRF (22–24) и перерендерить; промежуточные рендеры не коммитить.
- После рендера: `ffprobe` (1080×1920, 30 к/с, длительность), громкость (audio.md), кадры из MP4 листом.
- Ссылка для пользователя: `https://github.com/<owner>/<repo>/blob/<branch>/rolikN/out/rolikN.mp4`.

## Что отдавать пользователю
1. Перед рендером: листы ключевых кадров (+ лист с безопасной зоной), при необходимости превью 540×960.
2. Финал: ссылка, параметры файла, краткий список сцен, что проверено, что стоит проверить ему
   (расхождения текста и озвучки, спорные формулировки).
3. По запросу: описание для Instagram (хук + список аятов/хадисов с источниками), промт обложки.

## Технические грабли (уже решённые)
- **Шрифты** грузить локально через `@remotion/fonts` (в закрытых окружениях рендер не может скачать
  Google Fonts). Lora upright/italic, Montserrat variable, Amiri — в `public/fonts` (`scripts/get_fonts.sh`).
- **Remotion-шаблон** добавляет `out` в .gitignore — убрать.
- **faster-whisper**: декодировать ffmpeg в f32 и подавать массив (av.open падает на некоторых файлах).
- **Огласовки** у текста с `background-clip: text` обрезаются — нужен padding по вертикали.
- **Замер текста** во flex-контейнерах через Range давал сдвиг — `SafeProbe` меряет текстовые узлы
  относительно `[data-reel-root]`.
- **CSS `filter: url(#svgFilter)`** на `<Img>` работает в рендере (жар, распад).
- **Удаление по маске переменной** — пиши `"${DIR:?}"/*.jpg`, чтобы пустая переменная не превратилась в `/*`.
- **Голосовые из мессенджеров** тихие (≈ −30 LUFS) — prep_voice поднимет; добавь `--denoise`.
- **Длинный рендер** запускай в фоне и дождись уведомления, не опрашивай в цикле.
